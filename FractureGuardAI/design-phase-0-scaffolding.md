# Phase 0 — Repo Scaffolding & Docker Compose

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the monorepo skeleton, shared environment config, and a Docker Compose stack that brings all four services up locally with Azure service substitutes.

**Architecture:** All four services run as Docker containers. Azure Service Bus is replaced by RabbitMQ, Cosmos DB by its Linux emulator, Azure AI Search by FAISS, and Azure Entra ID by a hardcoded dev JWT. A single `docker compose up` starts the entire stack.

**Tech Stack:** Docker 27+ · Docker Compose · RabbitMQ 3.13 · Cosmos DB Linux Emulator

**Must complete before:** All other phases depend on this phase.

- [ ] **Step 4: Create `docker-compose.yml`**

```yaml
version: "3.9"

services:
  rabbitmq:
    image: rabbitmq:3.13-management
    ports:
      - "5672:5672"
      - "15672:15672"
    environment:
      RABBITMQ_DEFAULT_USER: guest
      RABBITMQ_DEFAULT_PASS: guest
    healthcheck:
      test: ["CMD", "rabbitmq-diagnostics", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  cosmos-emulator:
    image: mcr.microsoft.com/cosmosdb/linux/azure-cosmos-emulator:latest
    ports:
      - "8081:8081"
    environment:
      AZURE_COSMOS_EMULATOR_PARTITION_COUNT: 3
      AZURE_COSMOS_EMULATOR_ENABLE_DATA_PERSISTENCE: "false"

  fractureguard-predictor:
    build: ./fractureguard-predictor
    env_file: .env
    depends_on:
      rabbitmq:
        condition: service_healthy
    ports:
      - "8001:8001"

  fractureguard-notifier:
    build: ./fractureguard-notifier
    env_file: .env
    ports:
      - "3001:3001"

  fractureguard-api:
    build: ./FractureGuard.Api
    env_file: .env
    depends_on:
      rabbitmq:
        condition: service_healthy
      cosmos-emulator:
        condition: service_started
      fractureguard-notifier:
        condition: service_started
    ports:
      - "5000:8080"

  fractureguard-dashboard:
    build: ./fractureguard-dashboard
    ports:
      - "4200:80"
    depends_on:
      - fractureguard-api
      - fractureguard-notifier
```
