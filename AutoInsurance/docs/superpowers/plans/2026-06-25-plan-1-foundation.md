# Auto Insurance Platform — Plan 1: Foundation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the complete solution structure, shared types, domain entities, EF Core migrations runner, Ocelot API Gateway with dual-mode authentication, and Docker Compose orchestration — producing a running baseline that all subsequent API and frontend plans build on.

**Architecture:** One `AutoInsurance.Domain` class library holds all entity POCOs; one `AutoInsurance.Migrations` console app applies the full schema on startup; five domain API projects each have their own `AppDbContext` scoped to their tables; an Ocelot gateway sits in front of all APIs with JWT validation switchable between mock (local) and Azure AD B2C (cloud) via an environment variable.

**Tech Stack:** .NET 10, Entity Framework Core 10, Ocelot 23.x, SQL Server 2022, Docker Compose (Compose specification), xUnit, FluentAssertions, Moq

## Global Constraints

- Target framework: `net10.0` on all projects
- Minimal API style `Program.cs` — no `Startup.cs`
- Docker Compose specification format (no `version:` key)
- SQL Server 2022 image: `mcr.microsoft.com/mssql/server:2022-latest`
- Azurite image: `mcr.microsoft.com/azure-storage/azurite`
- All runtime config via environment variables — no `appsettings.*.json` baked into images
- Authentication toggled by `Auth__Mode=mock|b2c` environment variable
- Entity Framework uses FluentAPI configuration only — no data annotations on entities
- All primary keys are `Guid`, defaulting to `Guid.NewGuid()` in the entity constructor
- `DateTime` fields use `DateTime.UtcNow`

```csharp
namespace AutoInsurance.Shared;

public class Result
{
    public bool IsSuccess { get; }
    public string? Error { get; }

    protected Result(bool isSuccess, string? error)
    {
        IsSuccess = isSuccess;
        Error = error;
    }

    public static Result Success() => new(true, null);
    public static Result Failure(string error) => new(false, error);
}

public class Result<T> : Result
{
    public T? Value { get; }

    private Result(bool isSuccess, T? value, string? error) : base(isSuccess, error)
    {
        Value = value;
    }

    public static Result<T> Success(T value) => new(true, value, null);
    public static new Result<T> Failure(string error) => new(false, default, error);
}
```
